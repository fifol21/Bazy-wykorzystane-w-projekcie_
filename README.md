# Zbiory Danych do Testowania Modeli

Witaj w repozytorium przechowującym **zbiory danych** (datasets) wykorzystywane w ramach projektu do testowania, walidacji i ewaluacji modeli.

Repozytorium to służy jako centralne źródło danych testowych, zawierające reprezentatywne fragmenty większych baz danych.

## Formaty Danych

Dane zostały przygotowane w trzech formatach, aby pokryć różne scenariusze testowe:

| Format | Opis | Przeznaczenie |
| :--- | :--- | :--- |
| **`.csv`** | Dane tabelaryczne | Analiza strukturalna, testowanie regresji/klasyfikacji na danych ustrukturyzowanych. |
| **`.json`** | Obiekty zagnieżdżone | Testowanie parsowania złożonych struktur, konfiguracji lub danych API. |
| **`.txt`** | Surowy tekst | Przetwarzanie języka naturalnego (NLP), testowanie czyszczenia danych (data cleaning). |
